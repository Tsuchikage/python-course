### **Домашнее задание 3**: Библиотека для работы с матрицами

Цель задания — реализовать библиотеку для работы с матрицами, включая основные арифметические операции, оптимизацию и кэширование.

---

#### **3.1 Основные операции с матрицами**

- Создать класс матрицы, реализующий следующие операции через перегрузку операторов:
  - Сложение (`+`)
  - Умножение (покомпонентное `*` и матричное `@`)
- Обрабатывать исключения:
  - Поднимать `ValueError` в случае несоответствия размеров матриц.
- Шаги выполнения:
  1. Сгенерировать две матрицы размером `10x10` с использованием `np.random.randint(0, 10, (10, 10))` (задать seed=0 для воспроизводимости).
  2. Выполнить три операции (`+`, `*`, `@`) и сохранить результаты в файлы:
     - `matrix+.txt`
     - `matrix*.txt`
     - `matrix@.txt`
- **Артефакт**: три текстовых файла с результатами операций.

---

#### **3.2 Расширенные возможности через примеси**

- Создать класс матрицы с использованием примесей:
  - Реализовать все стандартные арифметические операции (с использованием NumPy).
  - Добавить через примеси:
    - Возможность записи объекта в файл.
    - Красивое текстовое представление матрицы в консоли (`__str__`).
    - Геттеры и сеттеры для полей класса.
- Ограничить количество методов непосредственно в классах.
- **Артефакт**: текстовые файлы аналогично задаче 3.1.

---

#### **3.3 Хэш-функция и кэширование**

- Дополнить класс матрицы:
  - Реализовать метод `__hash__`:
    - Хэш-функция должна быть уникальной и основанной на данных матрицы.
    - Дать краткое текстовое описание хэш-функции в комментариях к коду.
  - Настроить кэширование результатов матричного произведения на основе хэш-функции.
- Найти коллизии хэш-функции:
  - Создать 4 матрицы (`A.txt`, `B.txt`, `C.txt`, `D.txt`), такие что:
    - `hash(A) == hash(C)` и `A != C`
    - `B == D` и `A @ B != C @ D`
  - Сохранить результаты произведений:
    - `A @ B` в файл `AB.txt`
    - `C @ D` в файл `CD.txt`
  - Сохранить хэши матриц в файл `hash.txt`.

- **Артефакт**: семь файлов:
  - `A.txt`, `B.txt`, `C.txt`, `D.txt` — матрицы.
  - `AB.txt`, `CD.txt` — результаты произведений.
  - `hash.txt` — хэши матриц `AB` и `CD`.
